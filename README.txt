MOSaiNK Youth Initiative - Website
===================================
1. Open index.html to preview the site.

2. Set up form submissions (needed so applications reach you):
   - Create a free account at formspree.io and make a new form.
   - Copy the form URL (https://formspree.io/f/xxxxxxx).
   - In index.html find the SETTINGS block near the bottom and paste it into FORM_ENDPOINT.
   - Put your real email in EMAIL (also used in the footer).
   Until FORM_ENDPOINT is filled, forms open an email draft to EMAIL instead.

3. How approval works:
   Every submission (membership, debate, art) arrives in your Formspree inbox/email
   with status: Pending. The applicant sees "Pending review". You accept by
   contacting them (email/WhatsApp) and marking them approved in your own member list.
   (A real one-click Accept dashboard needs a small database backend; can be added later.)

4. Replace the # links in the footer with real Instagram/Facebook URLs.

5. Publish free with GitHub Pages: create a public repo, upload index.html,
   Settings -> Pages -> Deploy from branch -> main -> /root.

Forms included: General Member / Campus Ambassador / Volunteer / Partner-Other,
Debating Competition, Drawing & Art Competition (guardian consent).
